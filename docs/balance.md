## 3. ひな形の中身で変えたもの

形の特徴（design §3.7 の表）は保っている。

| ひな形 | 変えたこと | 理由 |
|---|---|---|
| 横陣 | 前列は最大で幅 − 4（12列なら8部隊）。あふれた前列の部隊は、後列の、前列の両端のすぐ後ろに置く | A11 の守り向きの編成（盾兵4・歩兵6）で、前列が戦場の端まで広がると、回り込む騎兵を受ける部隊がいない |
| 横陣 | 前列は、歩兵を中央、盾兵を外側に並べる | 前列の並べ方は表で決まっていない。総当たりの横陣の勝ち負けは、この変更では変わらなかった。動いたのは A11：守り向きの編成（盾兵4・歩兵6）で前列からあふれて後列の両端に回る部隊が、歩兵から盾兵に変わった。回り込んできた騎兵を正面で跳ね返すようになり、守る側の得点率が上がった（そのあと騎兵の数字で 0.675 に合わせた） |
| 鋒矢 | 矢じりの先頭（いちばん前の2マス）を歩兵にし、騎兵（本陣狙い）はそのすぐ後ろの矢じりに置く | 騎兵が先頭だと、横陣の正面の盾兵に当たって跳ね返され、溶ける |

## 4. 気になっていること

- **勝ち負けが種でほとんど変わらない。** ばらつき（0.9〜1.1）は刻みごとに引くので、長い戦いでは平均されて効かない。違うひな形どうしの組は、ほぼ 0.00 か 1.00 になる。A7 は、組の勝ち負けの向きだけで通っている。そのため、数字を少し動かすと、組ごと結果が入れ替わりやすい。A11 も、0.1 から 1.0 のあいだを少しの数字の差で行き来した（いまは 0.675）。
- **本陣狙いの騎兵が、盾の壁の前で止まる。** 本陣のすぐ前に壁があると、本陣へ向かう力と、壁から離れる力がつり合う。騎兵は壁の前で数秒〜十数秒止まり、弓に撃たれる（鶴翼 対 鋒矢で見える）。
  - 試したこと：離れる力のうち本陣から遠ざかる成分を捨て、横の成分だけを使う形。止まらなくなったが、鋒矢が横陣に勝てなくなり（0.00）、A7 が通らなくなった（強さ 1.0〜3.0、距離 2.5〜4.5、騎兵を先頭にした鋒矢、の8通り）。
  - 「離れる向きの力を足す」という決まりの書き方に近いのは、いまの形（力をそのまま足す）なので、いまの形のままにしている。
- **A1 の横陣の逆順は 0.600 で、範囲のちょうど上の端。** 種は固定なので、テストは毎回同じ結果で通る。数字を動かすと外れる可能性がある。
- **本陣狙いの部隊は、本陣以外の敵とはほとんど戦わない。** 避ける力が 2.0 だと、近接の距離（約 1.0）にいる敵1部隊からの力は 0.6 × 2.0 = 1.2 になり、本陣へ向かう力 1 を上回る。進む向きが敵からそれるので、「進む向きの正面（50°以内）にいれば戦う」に当てはまるのは、ほぼ真正面の本陣だけになる。A7 は、この強さに頼って通っている（横陣が負けるのは鋒矢の 0.00 だけ）。
- **A8 の突撃・堅守の場面は、選んで決めた。** ひな形の組・翼（全軍・中央）・刻み（4・8・15秒）を総当たりし、前後の刻みでも結果が変わらない組を選んだ（突撃：鶴翼 対 偃月。どの刻み・翼でも 1.00。堅守：鶴翼 対 魚鱗。中央へ 4・8 秒で 1.00、15 秒では 0.00）。組によっては、隣の刻みで 0 と 1 が入れ替わる（横陣 対 鋒矢の全軍堅守は、4秒 1.00・8秒 0.00・15秒 1.00）。号令の効き目は、出す時機に強く左右される。
